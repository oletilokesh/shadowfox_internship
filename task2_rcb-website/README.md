                🏏 Built a Fully Responsive RCB Fan Website!

🚀 Excited to share that I designed and developed a fully responsive IPL team website dedicated to *Royal Challengers Bangalore (RCB)*! 🏏🔥

This project was created as part of my web development learning journey and focuses on delivering an engaging fan experience with modern frontend technologies.

🧑‍💻 Key Features:
✔ Dynamic player cards using JSON data
✔ Match schedules & team statistics visualized with Chart.js
✔ Fan voting and comment system using localStorage
✔ Embedded YouTube anthem for an interactive feel
✔ Professional dark-themed UI with smooth animations
✔ Mobile-first, fully responsive design
✔ GitHub-hosted and deployed using GitHub Pages

✨ Additional Highlights:
🔹 Interactive and user-friendly interface
🔹 Organized and reusable JavaScript structure
🔹 Real-time style interactions and animations
🔹 Optimized layout for desktop, tablet, and mobile users
🔹 Improved frontend design and deployment experience
